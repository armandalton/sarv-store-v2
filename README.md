# SARV Website — نسخه به‌روزشده

این نسخه برای GitHub Pages آماده شده و شامل:
- خانه، محصولات، درباره سرو، ارتباط و مجله سرو
- ۱۱ محصول ادویه و ۶ محصول حبوبات
- اندازه‌های ادویه: ۴۵ و ۸۰ گرم
- اندازه‌های حبوبات: ۴۵۰ و ۸۰۰ گرم
- فیلتر ادویه / حبوبات
- نمایش قیمت‌های فعلی برای وزن‌هایی که قیمت آن‌ها در پروژه موجود بود؛ وزن‌های جدید به فروشگاه هدایت می‌شوند.
- اعلام واضح «۲۰٪ تخفیف خرید فروشگاهی»
- تأکید روی انتخاب «پک فروشگاهی» و خودداری از انتخاب تکی برای سفارش فروشگاهی
- ۶ مقاله آماده در بخش مجله
- استفاده از تصاویر جدید فایل `Got-sarv 2`
- بخش اختصاصی کاتالوگ ادویه و حبوبات
- طراحی responsive برای موبایل و دسکتاپ
- لینک خرید به `https://sarvco.mydigify.app`

## قرار دادن لینک کاتالوگ‌ها

در `index.html` و `products.html` دو عبارت زیر را با لینک واقعی فایل PDF یا صفحه کاتالوگ جایگزین کن:

- `CATALOG_SPICES_URL`
- `CATALOG_LEGUMES_URL`

اگر PDFها را در همین GitHub repository قرار بدهی، می‌توانی مثلاً از مسیر نسبی مثل `assets/catalogs/spices.pdf` استفاده کنی.

## قیمت‌ها

قیمت‌های وزن‌های فعلی بر اساس اطلاعات موجود در پروژه تنظیم شده‌اند. برای وزن‌های ۸۰ گرم و ۸۰۰ گرم، تا زمانی که قیمت نهایی مشخص شود، سایت کاربر را به فروشگاه هدایت می‌کند.

## تصاویر

تصاویر جدید ادویه در:
`assets/new-spices/`

تصاویر بسته‌بندی قبلی حبوبات در:
`assets/products/`

قرار گرفته‌اند.
